💰 Salle 3 - La Cale au Trésor 💰

La Cale Mystérieuse

Vous descendez dans la cale du navire. L'air est humide et vous entendez des gouttes d'eau... Des coffres sont empilés partout !

Votre dernière mission :

Pour ouvrir le coffre au trésor, vous devez :

  1. Trouver le code secret caché dans les commentaires HTML
  2. Corriger le type du champ de saisie pour qu'il accepte le bon format
  3. Entrer le code dans le champ approprié

🗝️ Serrure du Coffre au Trésor

Indices pour la recherche

  • Le code secret est au format téléphone américain
  • Regardez attentivement dans les commentaires HTML
  • Le champ input doit avoir le type approprié pour un numéro
  • Méfiez-vous des fausses pistes !
Astuce : Utilisez Ctrl+F (ou Cmd+F) dans les outils de développement pour chercher "code secret" dans les commentaires !
❌ Quelque chose ne va pas... Vérifiez le type du champ et le code saisi !
✅ Excellent ! Le coffre s'ouvre... Le trésor vous attend !
Récupérer le Trésor ! 🏆
