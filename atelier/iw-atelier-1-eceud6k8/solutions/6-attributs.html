Questions de réflexion :

La différence principale entre id et class est qu'un ID doit être unique dans la page (un seul élément peut l'avoir), tandis qu'une classe peut être appliquée à plusieurs éléments.

Non, on ne peut pas avoir plusieurs éléments avec le même id car cela violerait les standards HTML et pourrait causer des problèmes de navigation et de JavaScript.

Oui, plusieurs éléments peuvent avoir la même class. C'est même le but principal des classes : permettre de styliser ou de cibler un groupe d'éléments similaires. Exemple : tous les boutons d'une page peuvent avoir la classe "btn".
