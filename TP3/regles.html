    • Règles du challenge de calcul mental de Sami Sanad

    • L’objectif du jeu est de répondre correctement à une série de 5 calculs mathématiques le plus rapidement possible en entrant son résultat à l’endroit désigné.
    • Vous devez calculer mentalement vos réponses.
    • Vous avez un maximum d’une minute pour répondre à chaque question, après quoi, si vous n’avez pas répondu, vous passerez automatiquement à la question suivante.
    • Le challenge doit être réalisé individuellement.
    • Vous ne pouvez pas utiliser de feuilles, crayons, calculatrices ou autres outils pour calculer vos réponses.
    • Vous pouvez compter avec vos doigts.
    • Si vous entrez une mauvaise réponse, vous êtes autorisé à en entrer une autre autant de fois qu’il vous faudra, mais vous subirez une pénalité de cinq secondes pour chaque mauvaise réponse.
    • Le score est calculé de cette façon : nombre de secondes restantes Question1 - (5 * nombres de mauvaises réponses) + nombre de secondes restantes Question2 - (5 * nombres de mauvaises réponses), etc.
